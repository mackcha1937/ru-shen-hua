# 入神话 · 可运行 MVP

“入神话”是一款面向普通消费者的 AI 互动中国神话产品。用户先通过类似豆包的单轮对话生成穿越者角色，再进入神话场景探索线索。每一次选择都会写入“神话记忆”，持续改变 NPC 关系、下一章任务和最终生成的小说、动画剧本与动态漫预告。

当前完整开放第一卷《女娲补天》，包括：

- 照片导入与对话式角色创建；
- 10 个中国神话故事入口；
- 画面热点探索：五色石、黑龙鳞、芦灰、巨鳌足印；
- “巨鳌之约”与“黑龙开口”连续分支；
- 3 条黑龙主分支、1 条自由输入隐藏冲突分支、每条各 3 个后续决定；
- 持续记录并展示神话记忆；
- 根据角色和选择生成个性化小说、90 秒动画分镜、可播放动态漫概念预告；
- 下载小说 TXT 和完整选择档案 JSON；
- 手机与桌面端响应式布局、本地自动存档。

## 运行

这是零依赖静态应用。在项目目录运行：

```bash
python3 -m http.server 4173
```

然后打开 <http://localhost:4173>。也可以直接双击 `index.html`，但浏览器对剪贴板和本地文件的权限可能更严格。

## 首版验证重点

不要先验证“AI 能不能写长故事”，而要验证三个更关键的问题：

1. 用户是否愿意在 60 秒内完成角色创建；
2. 用户是否能感受到自己的选择在后面真的产生影响；
3. 用户是否愿意分享带有自己名字和角色设定的动态漫预告。

## 真实 AI 接入

当前版本把完整体验做成了可离线试玩的确定性叙事引擎，便于先验证产品，而不需要 API 密钥。正式版按四个独立能力接入：

1. **角色视觉生成**：照片 + 对话得到的性格/服装/身份，生成固定角色设定图，并保存角色一致性参数；
2. **叙事导演**：输入原典知识、用户角色、神话记忆和本幕约束，只生成当前一幕与 2–3 个真正不同的动作；
3. **状态裁判**：把自由输入归类为行动，更新人物关系、风险、物品和承诺，不直接写散文；
4. **内容工厂**：在一局结束后，使用同一份选择档案分别生成小说、剧本、分镜图与视频。

推荐后端始终保存结构化状态，而不是只把聊天记录反复塞给模型。接口与状态设计见 [AI 接入说明](docs/AI-INTEGRATION.md)。
